## 📐 โครงสร้างข้อมูล

ระบบครอบคลุม **4 ยุทธศาสตร์** รวม **11 ตัวชี้วัด (KPI)**:

### ยุทธศาสตร์ที่ 1 — ส่งเสริมและยกระดับการผลิตสู่มาตรฐานเกษตรมูลค่าสูง
- **หน่วยงานรับผิดชอบ:** สำนักงานเกษตรและสหกรณ์จังหวัดหนองบัวลำภู
- **ช่วงเวลา:** 1 ต.ค. 2567 – 30 ก.ย. 2569
- KPI 1.1: มูลค่าสินค้าเกษตรที่ได้รับมาตรฐาน (PGS, GAP, Organic, GI) → เพิ่มขึ้น ≥5%/ปี
- KPI 1.2: จำนวนกลุ่มเกษตรกรที่ได้รับการรับรองมาตรฐาน → เพิ่มขึ้น ≥5%/ปี

### ยุทธศาสตร์ที่ 2 — การแปรรูปและสร้างมูลค่าเพิ่ม
- **หน่วยงานรับผิดชอบ:** สำนักงานพัฒนาชุมชนจังหวัดหนองบัวลำภู
- **ช่วงเวลา:** 1 ต.ค. 2567 – 30 ก.ย. 2569
- KPI 2.1: มูลค่าผลิตภัณฑ์แปรรูป → เพิ่มขึ้น ≥5%/ปี
- KPI 2.2: จำนวนผู้ประกอบการที่ได้รับการถ่ายทอดเทคโนโลยีแปรรูป → เพิ่มขึ้น ≥5%/ปี
- KPI 2.3: จำนวนผลิตภัณฑ์แปรรูปที่ได้รับมาตรฐานออกสู่ตลาด → เพิ่มขึ้น ≥5%/ปี

### ยุทธศาสตร์ที่ 3 — การพัฒนาการตลาดและสร้างแบรนด์
- **หน่วยงานรับผิดชอบ:** สำนักงานพาณิชย์จังหวัดหนองบัวลำภู
- **ช่วงเวลา:** 1 ต.ค. 2567 – 30 ก.ย. 2568
- KPI 3.1: มูลค่าการจำหน่าย → เพิ่มขึ้น ≥10%/ปี
- KPI 3.2: จำนวนผลิตภัณฑ์ที่ยื่นขอใช้ตรา Nong Bua Lamphu Brand → ≥15%/ปี
- KPI 3.3: ความพึงพอใจผู้บริโภคต่อ Nong Bua Lamphu Brand → ≥90%

### ยุทธศาสตร์ที่ 4 — การสร้างความเข้มแข็งให้เกษตรกรและสถาบันเกษตร
- **หน่วยงานรับผิดชอบ:** สำนักงานเกษตรจังหวัดหนองบัวลำภู
- **ช่วงเวลา:** 1 ต.ค. 2567 – 30 ก.ย. 2568
- KPI 4.1: จำนวนเกษตรกรต้นแบบ → เพิ่มขึ้น ≥5%/ปี
- KPI 4.2: สัดส่วนวิสาหกิจชุมชนศักยภาพระดับดี → ≥35.6% ของฐานเดิม
- KPI 4.3: สัดส่วนสหกรณ์เกษตรเข้มแข็งระดับ 1-2 → ≥10%

## 🚀 ขั้นตอนการติดตั้ง

### ขั้นตอนที่ 1 — สร้าง Google Sheet + Apps Script

1. ไปที่ [Google Sheets](https://sheets.google.com) → สร้าง Spreadsheet ใหม่
2. ตั้งชื่อเช่น `Roadmap_เกษตรเพิ่มมูลค่า_หนองบัวลำภู`
3. ไปที่เมนู **ส่วนขยาย** → **Apps Script**
4. ลบโค้ดเก่าทั้งหมด แล้ววาง Code จากไฟล์ `Code.gs`
5. กด **บันทึก** (Ctrl+S)

### ขั้นตอนที่ 2 — รันฟังก์ชัน Setup ครั้งแรก

1. ในหน้า Apps Script เลือกฟังก์ชัน `setupSheets` จาก Dropdown
2. กด **▶ Run**
3. จะมีหน้าต่างขอสิทธิ์ → กด **อนุญาต**
4. ระบบจะสร้าง 3 ชีตอัตโนมัติ: `KPIData`, `KPIHistory`, `Users`
5. พร้อมสร้าง Admin เริ่มต้น (admin / admin1234)

### ขั้นตอนที่ 3 — Deploy เป็น Web App

1. กด **ทำให้ใช้งานได้** (Deploy) → **การทำให้ใช้งานได้แบบใหม่** (New deployment)
2. ประเภท: **เว็บแอป** (Web app)
3. ตั้งค่า:
   - คำอธิบาย: `Roadmap API v1`
   - เรียกใช้ในฐานะ: **ฉัน** (Me)
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน** (Anyone)
4. กด **ทำให้ใช้งานได้** (Deploy)
5. **คัดลอก URL** ที่แสดง (ขึ้นต้นด้วย `https://script.google.com/macros/s/...`)

### ขั้นตอนที่ 4 — ตั้งค่า Dashboard

1. เปิดไฟล์ `roadmap_agritech_dashboard.html` ด้วย Text Editor
2. ค้นหา `%%APPS_SCRIPT_URL%%`
3. แทนที่ด้วย URL จากขั้นตอนที่ 3
4. บันทึกไฟล์

### ขั้นตอนที่ 5 — ทดสอบ

เปิดไฟล์ HTML ในเบราว์เซอร์ แล้วเข้าสู่ระบบด้วย:
- **Username:** `ARG001`
- **Password:** `039001`

## 💡 การใช้งาน

### การกรอกข้อมูล

1. เข้าสู่ระบบ
2. คลิกแท็บ **ยุทธศาสตร์ 1–4** ที่ต้องการกรอก
3. ในตาราง KPI กรอก:
   - **ฐานเดิม** — ค่าตั้งต้นจากผลงานเดิม
   - **ผลงานรอบเดือน** — ผลงานในเดือนที่รายงาน
   - **ผลงานสะสม** — ผลงานสะสมทั้งหมด
   - **เดือนที่รายงาน** — เลือกจาก Dropdown
4. ระบบจะ **คำนวณ % เปลี่ยนแปลง** อัตโนมัติพร้อมแสดง Progress Ring
5. กราฟจะอัปเดตทันทีทุกครั้งที่กรอก

### การบันทึก

- **บันทึกลง Google Sheet** — กดปุ่ม `💾 บันทึกลง Google Sheet`
- **ส่งออก CSV** — กดปุ่ม `📥 ส่งออก CSV` เพื่อดาวน์โหลดไฟล์

### การดูภาพรวม

คลิกแท็บ **📊 ภาพรวม** จะแสดง:
- KPI Card สรุป (จำนวนยุทธศาสตร์, KPI ทั้งหมด, สถานะการกรอก, ค่าเฉลี่ย %)
- กราฟ Bar — ผลงานสะสมรวมรายยุทธศาสตร์
- กราฟ Radar — สัดส่วนความครบถ้วนข้อมูล
- กราฟ Line — แนวโน้มผลงานรายเดือน
- กราฟ Doughnut — เปรียบเทียบสัดส่วนผลงาน

## 🌐 การ Deploy ขึ้น GitHub Pages

1. สร้าง Repository ใหม่บน GitHub
2. อัปโหลดไฟล์ `roadmap_agritech_dashboard.html` (เปลี่ยนชื่อเป็น `index.html`)

6. กด **Save**
7. รอ 1–2 นาที จะได้ URL: `https://username.github.io/repo-name/`

## ❓ คำถามที่พบบ่อย

**Q: กรอกข้อมูลแล้วรีเฟรชหน้าเว็บ ข้อมูลหายไหม?**
> A: ข้อมูลจะถูกเก็บใน localStorage ของเบราว์เซอร์ ดังนั้นถ้าใช้เครื่องเดิมจะยังอยู่ แต่แนะนำให้กด "บันทึกลง Google Sheet" เสมอเพื่อความมั่นใจ

**Q: เปิดจากหลายเครื่องพร้อมกันได้ไหม?**
> A: ได้ แต่ข้อมูลจะแยกตาม localStorage ของแต่ละเครื่อง ข้อมูลกลาง (Google Sheet) จะอัปเดตเมื่อกดบันทึก

**Q: ลืมรหัสผ่าน Admin ทำอย่างไร?**
> A: ไปที่ Google Sheet → ชีต `Users` → แก้ไขรหัสผ่านได้โดยตรง หรือล้าง localStorage ในเบราว์เซอร์แล้วจะกลับเป็นค่าเริ่มต้น (ARG001 / 039001)

**Q: อยากเพิ่ม KPI ใหม่ทำอย่างไร?**
> A: แก้ไขตัวแปร `STRATEGIES` ในไฟล์ HTML โดยเพิ่ม object ใหม่ใน array `kpis`

**Q: Deploy แล้วขึ้น CORS Error?**
> A: ตรวจสอบให้แน่ใจว่า Apps Script deploy เป็น "Anyone" และใช้ `mode: 'no-cors'` ในการ fetch

**Q: อัปเดต Apps Script แล้วไม่มีผล?**
> A: ต้องสร้าง Deployment ใหม่ทุกครั้ง (New deployment) ไม่ใช่แค่ Save code เฉยๆ
